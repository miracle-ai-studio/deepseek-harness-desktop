APPKITWKWEBVIEWCORDISDSH

01 / INTENT

桌面体验，
不改变 DSH 的内核。

原生层只做它最擅长的事：窗口、菜单、文件面板与系统交互。Agent Loop、工具、权限和持久化仍由可组合的插件体系负责。

01

原生窗口

AppKit 菜单、查找、缩放、文件选择与下载，遵循熟悉的 macOS 交互。

02

插件原生

标准 dsh.bundle 与 Cordis 生命周期，可安装、可配置，也可由 profile 完整管理。

03

权限不绕行

页面没有原生 Shell 后门。所有工具执行继续经过 DSH capability 与权限策略。

02 / ARCHITECTURE

轻量连接，
完整能力。

Cordis 插件等待现有 Web Host 就绪，再把精确的本地地址交给原生 App。没有第二套 Session，没有重复的权限系统。
